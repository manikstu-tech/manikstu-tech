# MEMORY.md Sync Rule

Whenever you make any meaningful code, UI, backend, database, configuration, or feature change:

1. **Update MEMORY.md** with the latest changes.
2. **Remove or edit outdated information**; avoid duplicates.
3. **Before every git commit and git push**, verify that `MEMORY.md` is up to date and included in the commit.
4. **Never commit/push project changes** while leaving `MEMORY.md` outdated.

**Workflow Rule:**
`Code Change → Update MEMORY.md → Commit → Push`
