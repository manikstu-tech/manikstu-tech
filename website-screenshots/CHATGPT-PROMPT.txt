# ChatGPT Prompt — Manikstu Agro Mobile Version Design

Use this prompt with ChatGPT (GPT-4o or GPT-4o with Vision) along with the attached screenshots as reference images to design a mobile-optimized version of the Manikstu Agro website.

---

## Prompt for ChatGPT:

You are a senior UI/UX designer specializing in mobile-first web design. I am sharing screenshots of a desktop website for **Manikstu Agro** — a goat farming and agricultural company based in Odisha, India. Your task is to design a complete mobile version (375px width, iPhone standard) that maintains the exact same brand identity, color palette, typography hierarchy, and visual language — but optimized for mobile screens.

### DESIGN RULES:

1. **Touch targets:** Minimum 44x44px for all interactive elements
2. **Spacing:** Use 16px base spacing, 24px between sections
3. **Font sizes:** Hero heading 28-32px, section headings 22-24px, body 14-16px
4. **Buttons:** Full-width on mobile for primary CTAs
5. **Images:** Use aspect ratios that work on mobile (16:9 for heroes, 1:1 for products)
6. **Sticky elements:** Bottom CTA bar for product pages, floating WhatsApp button
7. **Loading:** Consider skeleton states and image lazy loading
8. **Accessibility:** Proper contrast ratios, readable font sizes, clear hierarchy
